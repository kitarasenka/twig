ДЛЯ ВАС · ВОЗМОЖНОСТИ

Ежедневный Git
и трудные случаи.

Работает с вашим установленным Git — своего движка вместо него 🌱 Twig не подставляет.

  • Каждая команда на видуТочная команда, папка, вывод, код и время — в журнале. Запросы агента помечены MCP.
  • Undo для GitКоммит, merge, cherry-pick, checkout, stash и даже discard — правки сначала копируются в Git.
  • Проверки до commit и pushТесты, правила ветки и сообщения, поиск секретов — без ручных хуков.
  • Staging по строкамФайлы, ханки или отдельные строки. Дифф с номерами и правками внутри строки.
  • Rebase по плануПорядок перетаскиванием, squash выделенных, новые сообщения — до запуска.
  • Конфликты в три колонкиВаша версия, база и их — результат собирается построчно.
  • Ветки перетаскиваниемMerge, rebase, cherry-pick или push — команды видны до запуска.
  • 🌱 BugHunterПошаговый git bisect: какой коммит внёс баг.
  • Blame и история строкиВерсия до правки, reverse blame, история файла через переименования.
  • Дифф картинокРядом, шторкой, наложением или разницей — с рамками вокруг изменений.
  • ReflogПотерянные коммиты помечены, ветка восстанавливается под прежним именем.
  • Поиск по всей историиПо сообщению, хэшу, автору, пути и коду (-S, -G).
  • Марки и заметкиЦвет и текст на коммите — только у вас, не в репозитории.
  • Worktrees, сабмодули, LFSА ещё подписи коммитов, патчи, теги и обслуживание репозитория.
  • Учебная песочницаНастоящий репозиторий с remote: пробуйте merge и rebase без риска.
  • Обновления в один кликУстановщик сверяется с релизом по SHA‑256, сборка для macOS подписана и нотаризована.

Без аккаунта и телеметрии

Репозитории, марки и журнал остаются на компьютере. Сам 🌱 Twig ходит в сеть только за проверкой обновлений (её можно выключить) и за фоновым fetch — если вы его включили.

Установка и подпись

Сборка для macOS подписана сертификатом Apple Developer ID и нотаризована — без предупреждения «не удаётся проверить разработчика». Установщик Windows пока без цифровой подписи: SmartScreen может предупредить при первом запуске. Git устанавливается отдельно.

macOS: откройте .dmg и перенесите приложение в «Программы». Windows: запустите установщик .exe. Debian / Ubuntu: установите пакет .deb. Другие Linux: сделайте .AppImage исполняемым (chmod +x) и запустите — установка не нужна. Дальше обновления приходят в самом приложении.
