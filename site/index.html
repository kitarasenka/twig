Выберите событие, условия и шаги проверки в редакторе. Запускайте тесты, проверяйте имя ветки, сообщение коммита или добавленные строки на секреты. При ошибке — предупреждение или блокировка операции.

03 / ЖУРНАЛ КОМАНД

От действия в интерфейсе
до фактической команды

Консоль показывает команду Git, каталог, вывод, код завершения и длительность. Последние 2 000 записей доступны после перезапуска. Журнал открывается на ваших действиях, всё остальное — во «Full History».

$ git log --oneline -3Код 0 · 12 мс · пример записи

В консоли можно вводить команды чтения: например, log, diff и status.

🌱 BUGHUNTER / GIT BISECT

Найдите коммит,
который внёс ошибку.

Укажите версию с багом и старую версию без него. BugHunter выбирает промежуточный коммит. Вы проверяете его и отмечаете: ошибка есть, ошибки нет или версию нельзя проверить.

Поиск использует git bisect — деление диапазона пополам. В панели видны тестовая версия и оценка оставшихся шагов. По завершении можно вернуться на исходную ветку.

ЕЖЕДНЕВНАЯ РАБОТА С GIT

От отдельных строк
до перестройки истории.

01 / STAGING

Коммит из выбранных строк

Добавляйте файлы, фрагменты или отдельные строки. Дифф нумерует строки с обеих сторон и выделяет конкретные правки внутри строки.

02 / REBASE

План до запуска

Переставляйте и объединяйте коммиты, меняйте сообщения. Весь план виден до выполнения; при остановке доступны продолжение, пропуск и отмена.

03 / КОНФЛИКТЫ

Три версии и результат

Ваша версия, общая база и их изменения — рядом. Собирайте результат построчно и отменяйте правки внутри редактора.

04 / BLAME

История конкретной строки

Посмотрите, кто изменил строку. Перейдите к версии до правки и её диффу. История файла учитывает переименования.

Установка и подпись

Сборки пока без цифровой подписи и нотариального заверения Apple: macOS и Windows могут показать предупреждение при первом запуске. Разрешайте открытие только сборки из доверенного источника. Git устанавливается отдельно.

macOS: откройте .dmg и перенесите приложение в «Программы». Windows: запустите установщик .exe. Debian / Ubuntu: установите пакет .deb. Другие Linux: сделайте .AppImage исполняемым (chmod +x) и запустите — установка не нужна. Настройки хранятся в пользовательском каталоге системы.
